## 本版变化

- README 保留 GitHub Releases 长地址，直链和 `gh-proxy.org` 两条命令均为 `curl -fsSL URL | sh`，日常安装无需 `-s -- --github-proxy` 等额外参数。
- 安装器下载菜单依次提供 `1` 仅官方直连、`2` 内置 `gh-proxy.org`、`3` 内置 `ghfast.top`、`4` 自定义 HTTPS 前缀、`5` 自动有限回退。选择自定义后才询问地址。
- 下载菜单直接回车只为本次使用 `auto`，保留既有策略；明确选择才保存。显式参数和环境变量仍用于自动化，且不被菜单覆盖。
- 自定义安装目录、可选 Bash/Zsh 注册、最终默认取消及从 `/dev/tty` 读取回答等边界沿用 v0.9.0；安装不关联外部 Codex、不安装或启动组件。

## 验证边界

本版公开验收须分别执行 README 的直链与 `gh-proxy.org` 无参数命令，由真实 PTY 回答下载方式、自定义目录与 Shell 注册。公开脚本、包和摘要的真实下载响应须与独立验签资产逐字匹配，再检查安装版本、实际 `bin/nido` 路径、输出激活命令及新 Shell 中的命令注册；失败不能用本地响应替代。

源码的 29 个真实 PTY 隔离场景覆盖各菜单选项、优先级、取消、空值、目录和注册委托，属于夹具测试。它们与功能提交的原生 CI 已通过，但不能替代本版公开资产的独立核验与安装验证。

仅在临时 HOME、软件目录和配置哨兵中执行安装验证。不挂载真实组件数据，不访问 Zenith-Dev，不运行 Codex、Mihomo、GDS 或系统服务。原有配置、认证、会话和数据保持原样。客户端仍只验证包摘要，不自动验证 Sigstore；第三方转发脚本需要信任对应服务。
